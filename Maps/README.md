##  Current status of created products 

This folder contains spatial products generated using the biodivMapR spectral-species workflow. The products represent spectral α- and β-diversity derived from MODIS NDVI time series and are intended to characterize spatial patterns of vegetation heterogeneity at the regional scale.

## The current set of products includes:

-Spectral α-diversity maps — spatial patterns of spectral-species richness derived from the selected moving-window configuration.

-Spectral β-diversity maps — spatial patterns of spectral community differentiation based on spectral-species composition.

-Raster outputs — spatial products provided in standard geospatial formats (e.g., GeoTIFF).

These products represent spectral diversity rather than direct taxonomic biodiversity and should be interpreted as spatial information on vegetation spectral heterogeneity and differentiation.
